# 放学以后 · 可调节街区

一个可在桌面和手机浏览器体验的交互式 Three.js 微缩街区原型。

## 手机操作

- 上方是完整三维画面，下方是可滚动控制面板；按钮不会浮在街区画面上。
- 用手指拖动画面旋转视角，双指缩放；点建筑进入室内。
- 下方“街区与店铺 / 季节与天气 / 音乐音效”快捷键会滚动到相应设置。
- 沿街浏览时，在下方面板点前进或后退；到校门后可切换朝向。
- 浏览器首次打开不会自动播放声音，点“开启声音”即可。

## 素材

室内设备和帆布鞋来自本项目 Blender 网格，屏幕与店内纸张为原创氛围图。店铺抹灰、木材、屋瓦、砖面、布料、沥青和铺地的物理材质来自 [ambientCG](https://ambientcg.com/)，按 CC0 使用。Three.js 及扩展组件见 `vendor/`。
